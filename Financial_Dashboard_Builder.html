Generate dashboard
Produces a standalone HTML file for the selected depot only.
HTML: This file is written in HTML — the same language every website on the internet is built from. It's essentially a set of instructions that tells a web browser (Edge, Chrome, etc.) what to display and how to lay it out — the text, the tables, the charts, the colours — all bundled into one file. When you open it, your browser reads those instructions and turns them into the dashboard you see.

There's no website involved and nothing gets uploaded anywhere — the file, and all the depot data inside it, lives entirely on your computer (or wherever you save or send it to). To share a dashboard with a GM, you send them this file directly — email, Teams, a shared drive, however you'd normally send a document — and they just double-click it to open it, no login and no internet connection needed.
